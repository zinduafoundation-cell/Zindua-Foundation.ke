# Zindua Foundation

A modern Next.js website for Zindua Foundation, designed to highlight the organization’s mission, youth empowerment work, stories, programs, and community impact.

## Live project

- GitHub: https://github.com/zinduafoundation-cell/Zindua-Foundation.ke

## Overview

Zindua Foundation connects young people with mentorship, opportunities, community support, and practical resources that help them grow into confident leaders and changemakers.

## Features

- Clean mission-driven homepage
- Program and impact-focused sections
- Community stories and volunteering CTAs
- Donation and membership entry points
- Responsive design for mobile and desktop
- Modern Zindua brand styling with emerald, ivory, and gold colors

## Tech stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Lucide icons

## Getting started

### Install dependencies

```bash
npm install
```

### Run the app locally

```bash
npm run dev
```

Then open:

```bash
http://localhost:3000
```

## Production build

```bash
npm run build
```

## Project scripts

```bash
npm run dev
npm run build
npm run start
npm run lint
```

## Deployment

This project is ready to deploy on platforms such as Vercel or similar Node.js hosting providers.

For Vercel, connect the GitHub repository and deploy the project using the default Next.js settings.
